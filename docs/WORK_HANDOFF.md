# ChatGPT Work 引継ぎ指示

## 対象
- Repository: `viaNEONIA/UI-Studio`（作成後）
- Baseline: v0.6
- Runtime: 静的HTML/CSS/JavaScript、PCブラウザ
- 目的: Android等のUIラフを作り、JSONをChatGPTに渡して実装仕様を共有する

## 最初の作業（優先順）
1. `index.html` のコード監査。実装機能と未実装・不具合を区別し、報告する。
2. Chromiumでの実操作検証。追加、移動、リサイズ、複数選択、グループ、Undo/Redo、JSON保存/読込、HTML出力、端末サイズ変更、制約を確認する。
3. Playwrightを導入して重要操作のE2Eテストを作成する。CIで再現可能にする。
4. 既存v0.6データの読み込み互換性を保ちつつ、必要ならソース分割を提案する。
5. バグを修正してからStackレイアウト等の追加開発に進む。

## 完了条件
- 変更はPull Requestで提出する。
- テストの実行コマンド・結果・未検証項目を明記する。
- UIのスクリーンショットはテストで取得した実画面を使い、生成イメージと混同しない。
- JSONの旧形式を壊さない。破壊的変更時は移行手順を添える。
- GitHub Pagesの公開状態を確認する。

## 注意
- 現在の `npm test` はスモークテストのみで、UI操作の正常性を保証しない。
- ユーザーのUI設計JSONに個人情報が含まれる可能性がある。テストにはダミーデータを使う。
- 外部コンテンツのHTML埋め込みはXSS等のリスクを検討する。
