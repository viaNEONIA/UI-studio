## PR #42

- 範囲指定スタンプ・背景透過・不透明度・登録前プレビューを実装。
- 未収録文字は通常／注釈編集用PDFで「〓」に置換し、警告と一覧TXTを出力。元のノートは保持。
- 承認済みラフのボタン配置、中央の表示切替、パネルアイコンの開閉連動と説明領域を実装。
