# UI Studio

PCブラウザでスマートフォンUIのラフを設計する、HTML/CSS/JavaScript製のプロトタイプエディターです。

> **現在の基準版: v0.6（試作）**。Chromiumでの操作テストをCIで実行します。正式なMaterial Design 3コンポーネント実装ではありません。

## 起動

**PC内で使うアプリです。** ビルド済みの `dist/index.html` を保存し、ChromeまたはEdgeで開きます。サーバー・GitHub Pages・実行時のインターネット接続は不要です。Node.jsも使用時には不要です。

自分でビルドする場合はNode.js 24系で `npm ci`、`npm run build` を順に実行します。Windows PowerShellでnpm.ps1の実行制限が出る場合は `npm.cmd ci`、`npm.cmd run build` を使ってください。外部HTMLなどの埋め込み内容は信頼できるものに限定してください。

## 既存機能（実装を含むが動作保証前）

- 画面・コンポーネント・レイヤー編集
- ドラッグ移動、サイズ変更、複数選択、グループ化
- グリッド表示、スマートガイド、スナップ
- 端末サイズ切替、倍率、レイアウト検査
- 制約ベースの位置・サイズ調整（v0.6）
- JSON保存・読込、HTML出力

## 開発上の原則

1. `index.html` はv0.6の原本として初回コミットし、以後の変更はPull Requestでレビューします。
2. 画面データはJSONを正本とし、HTML出力は生成物とみなします。
3. 新機能の前にブラウザE2Eテストを整備します。
4. JSONの後方互換性を壊す場合はマイグレーションを用意します。
5. ユーザーの設計データを無断で外部送信しません。

## PC用の配布版を取得する

GitHubの **Actions → CI → 成功した実行 → Artifacts → ui-studio-app** からZIPを取得し、展開した `index.html` をPCに保存して開きます。自動生成した配布物の保持期間は14日です。ダウンロード後にPCへ保存したファイルは引き続き使えます。

GitHubはソース管理・自動テスト・配布版の生成に使用します。Pagesへの自動公開ワークフローは使用しません。既に公開済みのPagesサイトを非公開にする場合は、リポジトリのSettings → Pagesで「Unpublish site」を実行してください。ワークフローの削除だけでは既存の公開サイトは消えません。

作業内容はJSONで保存してください。前回復元と保存済みプロパティは同じブラウザ・同じ保存場所での使用を前提とします。HTMLの移動やブラウザデータ削除に備え、JSONとプロパティ設定の書出しファイルを保存してください。

## A4・A3の資料作成

左側の「キャンバスプリセット」からA4・A3の縦／横を選択できます。切替時はキャンバス全体が見える倍率に自動調整します。1画面を1ページとして利用し、「＋画面」でページを追加します。

| 用紙 | 実寸 | キャンバス（CSS px） |
| --- | --- | --- |
| A4 縦 | 210 × 297 mm | 794 × 1123 |
| A4 横 | 297 × 210 mm | 1123 × 794 |
| A3 縦 | 297 × 420 mm | 1123 × 1587 |
| A3 横 | 420 × 297 mm | 1587 × 1123 |

96 CSS px/inの換算値を整数へ丸めています。JSONのversion:1とwidth/heightを引き続き使い、旧形式を変更しません。サイズはプロジェクト内の全画面共通です。切替時は既存の制約が適用されるため、部品をそのまま保つ場合は「サイズ変更時に制約を適用」をオフにしてください。PDF/PPTX出力にも用紙の実寸サイズを使用します。

## 線・矢印の作成

「線を描く」で直線・矢印・折れ線・曲線を選び、キャンバスをクリックします。直線と矢印は2点で確定。折れ線と曲線は点を順番に置き、「確定」またはEnterで完了、Escまたは「取消」で中止します。曲線は通過点の方向を滑らかにつなぎます。部品一覧から定形の線も追加できます。

線を選択すると、右側の「線の設定」で太さ1〜32pxのスライダー、12色パレット、任意色のカラーピッカーを使えます。区切り線にも太さと色を設定できます。線は移動・リサイズ・グループ化・Undo/Redoに対応し、HTMLへSVGとして出力します。線を選択すると各頂点に丸いハンドルが表示され、個別にドラッグして形を変更できます。元の部品枠の外にも移動でき、他の頂点の位置は保たれます。曲線のハンドルは曲がり方を決める制御点です。1回のドラッグは1回のUndoで戻せます。

旧JSONは引き続き読み込めます。新しい線はversion:1に追加のtype、points、stroke、strokeWidthを保存するため、新しい線を含むJSONを旧アプリで読み込むことは保証しません。

## 会議用資料・出力（ローカル処理）

開発は `npm ci && npm run build`。配布・起動には **`dist/index.html`** を使います。依存ライブラリ・PDFのCMap/標準フォントを同梱した単独HTMLのため、実行時のCDN接続は不要です。CIはビルド済みdistをPC用の配布物として保存します。リポジトリ直下のindex.htmlでも基本編集・レーザー・手のひら・拡大縮小・閲覧切替・画像取込・スタンプを使用できます。PDF取込とPDF/PPTX出力にはライブラリ同梱のdist/index.htmlが必要です。未ビルド版ではPDF/PPTX出力ボタンを無効化し、PDF取込を試した場合は理由を表示します。

1. A4/A3などのキャンバスサイズを選択して「PDF・画像を取り込む」。PDFは1ページを1編集ページに変換し、現在のキャンバス内へ縦横比を保って配置します。サイズは全ページ共通です。既存ページがあれば新しいページとして追加します。
2. 背景は常に最背面、初期状態でロック。表示/非表示・濃さ・差し替え・削除・ページに合わせるを操作できます。ロック解除すると背景をドラッグ移動できます。
3. 上に線・図形・テキストを追加します。「会議表示」で編集パネルを隠し、Teams側でブラウザのウインドウ共有を行います。ページ切替と手のひら移動も利用できます。
4. JSONは背景画像も含む再編集用正本。HTMLは背景を含めた単独閲覧用です。PDF/PPTXは全ページを画像合成して出力します。PPTXの図形・文字は個別に編集できません。A4/A3は実寸の用紙・スライドサイズを設定し、その他は96px/inで換算します。

背景を含むUndo履歴は文字数合計32Mi以内を目安に古い履歴を削除します（直前1件は保持）。

自動復旧データは端末内のIndexedDBへ保存します。前回分があると復旧/破棄の選択を表示し、選択前には上書きしません。保存失敗は画面に表示します。ブラウザのデータ削除・端末変更には引き継げないため、会議後はJSONを保存してください。JSONダウンロードのボタン操作は、保存先への書込み完了までを保証するものではありません。

取込はPDF 50MB/50ページ、画像25MBまで。背景は最長辺2400px以内に画像化します。元PDFファイル自体は保存せず、再表示用のページ画像を保存します。検索可能なPDFのテキストやベクターを維持する出力ではありません。暗号化/パスワード付きPDFは非対応です。

PDF/PPTX出力ではHTML部品（iframe）と外部URL画像を明示的なエラーにし、不完全な資料を黙って出力しません。外部URL画像は画像ファイルを背景として取り込んで使用してください。複雑な追加CSSには描画差が生じる場合があります。新規の背景フィールドを含むJSONを旧バージョンへ戻す互換性は保証しません。

### 背景の透明化
部品を選び、右側の「背景を透明にする」で背景だけを消せます。チェックを外すと元の色と透明度に戻ります。「背景の透明度」は0％（不透明）〜100％（完全に透明）で連続調整でき、文字色には影響しません。四角・文字を含む部品に適用でき、JSON保存・読込、HTML・PDF・PPTX出力にも反映されます。追加CSSで背景を指定している場合は、その指定が優先されます。

### 図形・会議操作
- Material 3の見出しをクリックすると部品一覧を折りたためます。図形・線・スタンプは別に表示します。
- 四角形・円／楕円・三角形を配置でき、塗りつぶしと枠線の色・透明度を独立して指定できます。枠線の太さ0は枠線なしです。
- レイヤー一覧の🔒/🔓ボタン、選択をまとめてロックするボタン、または選択部品の「レイヤーをロック」で移動・リサイズ・プロパティ編集・削除・整列を防止します。ロック解除はレイヤー一覧の鍵ボタンから行えます。ロック中の部品は選択できません。
- PNG・JPEG・WebP画像をスタンプとして取り込み、一覧から繰り返し配置できます。画像は長辺1024px以内のPNGへ変換し、スタンプ一覧と配置画像をJSONに含めます（最大30個）。PNGの透過背景を維持します。
- テキストと図形内の文字は横（左・中央・右）と縦（上・中央・下）の位置を選べます。
- キャンバス上でCtrl＋ホイールを操作すると、マウス位置を基準に5〜400％で拡大・縮小します。編集・閲覧・会議表示で共通です。
- 中ボタンを押しながらドラッグ、または矢印キーで表示領域を移動します。「手のひら移動」をONにすると左ボタンでもドラッグできます。矢印キーは文字入力やセレクト操作中には割り込みません。全体表示時でも余白を含めて移動できます。
- 線の2点目以降を置く際にShiftを押すと、直前の点から水平・垂直の近い方向に固定します。
- 「閲覧モード」では編集を止め、ページ移動・拡大縮小・手のひら移動・保存／出力・レーザーを使えます。「編集モードへ」で編集を再開します。「会議表示」は編集パネルを隠す表示切替です。
- 「レーザー：OFF」をクリックするとON表示に変わり、キャンバスの中央に赤い点を表示します。資料の上へマウスを動かすと追従します。編集画面・会議画面の両方で使用でき、Escで解除します。レーザーはJSON・HTML・PDF・PPTXには含めません。Teamsではこのブラウザのウインドウを共有してください。

### 線の水平・垂直固定と先端
「直線」を選び、始点をクリックしてからShiftを押したままマウスを動かすと、プレビューが水平・垂直の近い方向へ固定されます。そのまま終点をクリックして確定します。Shiftを離すと自由な角度へ戻ります。直線・矢印の頂点をドラッグして調整する場合も、Shiftで反対側の端点と水平・垂直に合わせられます。

線を選ぶと右側の「線の設定」に「始点の形」「終点の形」が表示されます。「なし・矢印・○」を各端で指定できます。○は白抜きで、先端は線の色・太さ・透明度に追従します。直線・矢印・折れ線・曲線に適用でき、JSON保存・読込とHTML・PDF・PPTX出力に反映されます。既存の矢印は設定の追加なしで従来の矢印先端を維持します。

### 用紙サイズ・Ctrl接続スナップ
キャンバスプリセットからA1（594×841mm）・A2（420×594mm）の縦横を選べます。PDF/PPTXは対応する実寸で出力します。「自由設定」では幅・高さをそれぞれ1〜20000 CSS pxで指定して「画面サイズを適用」を押します。

線・矢印・折れ線・曲線を選び、端点／頂点をCtrlを押したままドラッグすると、他の部品の中心・辺・角・三分割点に吸着します。通常の部品は外接枠の0・1/3・1/2・2/3・1の位置を縦横に組み合わせた交点、線は線上の端点・中央・三分割点を使用します。曲線は実際の曲線上を距離で分割した位置を使用します。ロックされた部品も吸着先にできます。吸着対象と位置は水色で表示し、Ctrlを離すと自由な位置合わせに戻ります。許容距離は表示倍率にかかわらず画面上10pxです。

新しい線を描く場合もCtrlでクリック位置を吸着できます。Shiftと併用する場合は水平・垂直を維持できる吸着点だけを使用します。この操作は端点座標の位置合わせで、部品移動への自動追従は行いません。座標は既存のJSONと各形式の出力に反映されます。


### スタンプ管理・画面設定・補助線

- スタンプはファイル選択時に複数画像を一括登録できます。一覧のチェックで複数選択し「選択を配置」「選択を削除」を使います。登録を削除してもキャンバス上の配置済み画像は残ります。一括配置・一括削除はそれぞれ1回のUndoで戻せます。
- 左側の「画面設定」にキャンバス寸法、PDF・画像取込、背景資料、表示倍率、グリッドを集約しました。「画面設定」「レイヤー」は見出しで折りたためます。
- 背景資料は各画面の `background` に保存される専用レイヤーです。通常の部品の選択・並べ替え・削除には含まれず、常に最背面です。専用レイヤーの×、または画面設定内の「背景を削除」で削除します。ロック中でも専用の削除操作は可能で、Undoで復元できます。
- 直線・矢印・折れ線・曲線を選択すると、右側で区間を選び制御点を追加できます。白い丸をドラッグすると隣接区間が連続して変形します。指定点の削除は最小2点まで。直線・矢印を折れた形にしても種類と先端設定を維持します。
- 作図用補助線は水平・垂直の位置指定、または2点指定で任意角度の無限直線を作成できます。Ctrlで線の作成点・制御点を補助線上や交点へ吸着できます。水平・垂直の補助線には通常部品のスマートガイドも吸着します。
- 補助線は個別削除と現在の画面内の一括削除に対応し、Undo/RedoとJSON保存・復旧の対象です。HTML/PDF/PPTX出力には含みません。各画面の省略可能な `guidelines` 配列を使用し、従来のJSONもそのまま読み込めます。上限は1画面1000本です。

### プロパティの保存・解像度プリセット・中央への全体表示

- 部品を選び、右側の「保存したプロパティ」で名前を付けて「現在の設定を保存」します。同名・同種類の設定は上書きされます。保存設定は種類別に選択・適用・削除でき、最大100件です。
- 保存対象は幅・高さ、色、透明度、線幅、先端の形、文字位置、角丸、文字サイズ、制約です。座標・表示文字・画像データ・ロック・グループ・追加CSS・画面遷移先は含めません。既存部品への適用はUndoできます。
- 「同じ種類の部品を次に作るとき自動適用」を有効にすると、次回作成時にも設定を使います。線をクリックで描く場合は描いた位置・形を保ち、色・太さなどを適用します。
- 保存設定はプロジェクトとは別に、このブラウザのlocalStorageに保存します。ページを閉じても保持しますが、ブラウザデータの削除で失われます。「設定を書き出す／設定を読み込む」で別端末・別の保存場所との間で移せます。設定読込は一覧を置き換え、不正なファイルは適用しません。保存に失敗した場合は画面に表示します。
- 画面設定にHD 1280×720、Full HD 1920×1080、QHD 2560×1440、2K（DCI）2048×1080、4K（UHD）3840×2160を追加しました。QHDと2Kは寸法を区別して表示します。
- 全体表示は編集・閲覧・会議表示で共通です。パンや拡大の後でもキャンバス全体を作業領域の上下左右中央に収めます。大きなキャンバスは5%未満まで縮小し、全体表示中のウインドウサイズ変更にも追従します。

### ダブルクリックでの文字編集・線幅スライダー

- 四角・円・三角・テキスト・ボタン・カードなど文字を表示する部品をダブルクリックすると文字編集欄を開きます。HTML部品はHTML断片を編集できます。画像・スタンプ・線・区切り線・進捗バー・スライダーは対象外です。
- Enterで改行、確定ボタンまたはCtrl＋Enterで反映、取消ボタンまたはEscで破棄します。日本語変換中のEnterは確定操作に使いません。編集の確定は1回のUndoで戻せます。グループ内でも編集するのはダブルクリックした部品だけです。
- ロック中・閲覧モード・レーザーON・手のひら移動ONのときは文字編集を開始しません。会議表示では編集可能です。
- 線幅はドラッグ中に線と数値を更新し、入力ごとにプロパティ全体を再描画しない方式に変更しました。ドラッグ1回をUndo1回で戻せます。図形の枠線にも0〜32pxのスライダーを追加し、数値欄と同期します。


### 角度ロック・レイヤー表示・Node.js 24

- 線を描く欄の「角度固定」で角度の刻みを0.1〜360°で指定できます。45°なら0°・45°・90°・135°・180°・225°・270°・315°の8方向、30°なら12方向、90°なら水平・垂直の4方向に吸着します。マウスに最も近い方向を選び、プレビューと確定位置を一致させます。0°の刻みは無効です。
- 直線・矢印・折れ線・曲線・2点指定の補助線、および線の制御点ドラッグに適用します。折れ線の制御点は直前点（先頭点の場合は次の点）を基準にします。Shiftを押している間は水平・垂直を優先し、Ctrlでは角度を維持できる位置だけへ吸着します。
- 部品をロックすると選択を解除します。キャンバス、一覧、Ctrl/Shiftの複数選択、グループ選択からも選択できません。レイヤー一覧の鍵ボタンで解除してから選択してください。ロック中の部品への接続スナップは使用できます。
- レイヤー一覧は「オブジェクト名 — 表示内容の先頭10文字」で識別します。絵文字を途中で分断せず、改行・項目区切りは空白にします。HTMLはタグやscript/styleを除いた文字、画像・スタンプはオブジェクト名を表示します。元のオブジェクト名と保存データは書き換えません。
- ビルド用Node.jsを24系に統一しました。package.json／package-lock.jsonのenginesは24.x、.nvmrcは24です。CIはNode.js 24を指定し、使用するActionsもNode.js 24対応版へ更新しています。

### レイヤー中心の操作画面

- 左ペインはレイヤー一覧を主役にし、ページ・図形／線／文字・補助線・スタンプ・Material 3・画面設定などは通常閉じます。上部のアイコンから対応する項目を開いて操作できます。図形・文字は直接追加でき、縦／横補助線はキャンバス中央に追加します。
- ロック中のレイヤー行を押すと、倍率を保ったまま対象の位置へ移動し、水色の破線で一時表示します。ロックと保存データは変更せず、編集対象として選択しません。解除済みの行は移動と選択を行います。閲覧モードでは行クリックによる移動だけが可能です。背景資料の専用行も移動に対応します。
- 背景／塗りつぶし・文字色にパレットを追加しました。任意色は従来の色入力で指定でき、透明度はパレット変更後も保ちます。背景の透明化ボタンとUndoにも対応します。
- ダブルクリックの文字編集欄にはサイズスライダー、数値入力、プレビューを同時表示します。文字とサイズは確定時にまとめて反映し、取消は両方を破棄、Undoは1回で元に戻します。
- PDF／PPTX出力は手のひらボタンの右、ズーム操作はキャンバス下中央に移しました。整列・グループ操作はプロパティ内にまとめています。ページは初期名を「ページ 1」「ページ 2」等とし、一覧のダブルクリックで名前を変更できます。元の資料名は背景情報に保持します。


### 枠線パレットと角度刻み

図形の枠線にも背景・文字色と同じ色パレットを追加しました。枠線の太さ、透明度、塗り、文字色は保持し、従来の任意色入力・設定保存・Undoと連動します。

角度固定は指定した1本の方向ではなく、0°を基準とした角度の刻みへ吸着する動作に変更しました。指定値が360°を割り切らない場合は、0°から360°未満の倍数方向のうち最も近い方向を使います。折れ線、矢印、補助線、端点／制御点のドラッグも同じ動作です。Shiftは水平・垂直を優先し、Ctrlの接続先も選ばれた方向を維持できるものに限ります。

### 線の選択とボタン状態
- 直線・矢印・折れ線・曲線は、外接長方形ではなく線の近く（最低12画面px幅）で選択します。長方形内の余白から背後のオブジェクトを操作できます。選択中も線に沿って強調し、変形は頂点をドラッグします。
- グループ化・整列は2個以上の選択、グループ解除はグループを含む選択、削除・前後移動は選択がある場合だけ利用できます。履歴なしのUndo/Redo、補助線なしの一括削除、未描画時の確定・取消も無効表示になります。
- レイヤーロックボタンは現在の状態に応じて「ロック」「ロック解除」を説明し、閲覧モードでは無効表示になります。

### 起動時の設定・復元と選択レイヤー
- 初回起動は「新規作成 — 画面設定」を表示します。キャンバスサイズ（プリセット・任意サイズ）を指定し、背景画像・PDFを任意で選んで開始します。資料は専用の最背面レイヤーに配置します。
- 前回の自動保存がある場合は、編集開始前に「前回を復元」「新規作成」を選びます。選択中・設定中・取込エラー時は前回データを上書きしません。「復元の選択に戻る」で戻れます。
- 選択レイヤーは編集画面だけで一時的に最前面になり、上に重なった部品があっても操作できます。選択解除後は元の重なり順に戻ります。保存・HTML・PDF・PPTX出力の重なり順は変えません。ロック中のレイヤーは編集選択できません。
