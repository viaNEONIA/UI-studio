# UI Studio

PCブラウザでスマートフォンUIのラフを設計する、HTML/CSS/JavaScript製のプロトタイプエディターです。

> **現在の基準版: v0.6（試作）**。実ブラウザでの操作テストは未完了です。正式なMaterial Design 3コンポーネント実装ではありません。

## 起動

`index.html` をChromeまたはEdgeで開きます。ビルド、インストール、サーバーは不要です。

GitHub Pagesを有効にした場合は、リポジトリの公開URLでも利用できます。外部HTMLなどの埋め込み内容は信頼できるものに限定してください。

## 既存機能（実装を含むが動作保証前）

- 画面・コンポーネント・レイヤー編集
- ドラッグ移動、サイズ変更、複数選択、グループ化
- グリッド表示、スマートガイド、スナップ
- 端末サイズ切替、倍率、レイアウト検査
- 制約ベースの位置・サイズ調整（v0.6）
- JSON保存・読込、HTML出力

## 開発上の原則

1. `index.html` はv0.6の原本として初回コミットし、以後の変更はPull Requestでレビューします。
2. 画面データはJSONを正本とし、HTML出力は生成物とみなします。
3. 新機能の前にブラウザE2Eテストを整備します。
4. JSONの後方互換性を壊す場合はマイグレーションを用意します。
5. ユーザーの設計データを無断で外部送信しません。

## GitHub Pages

Settings → Pages → Build and deployment → Source: **GitHub Actions** を選択してください。`main` へのpushで `.github/workflows/pages.yml` が実行されます。公開URLは通常 `https://viaNEONIA.github.io/UI-studio/` です（公開設定に依存）。

## テスト

Node.js 22以上で `npm ci && npm test`。Chromium E2Eは `npx playwright install --with-deps chromium` 後に `npm run test:e2e`。実行範囲・制限・監査結果は [`docs/V06_AUDIT.md`](docs/V06_AUDIT.md) を参照してください。

## A4・A3の資料作成

左側の「キャンバスプリセット」からA4・A3の縦／横を選択できます。切替時はキャンバス全体が見える倍率に自動調整します。1画面を1ページとして利用し、「＋画面」でページを追加します。

| 用紙 | 実寸 | キャンバス（CSS px） |
| --- | --- | --- |
| A4 縦 | 210 × 297 mm | 794 × 1123 |
| A4 横 | 297 × 210 mm | 1123 × 794 |
| A3 縦 | 297 × 420 mm | 1123 × 1587 |
| A3 横 | 420 × 297 mm | 1587 × 1123 |

96 CSS px/inの換算値を整数へ丸めています。JSONのversion:1とwidth/heightを引き続き使い、旧形式を変更しません。サイズはプロジェクト内の全画面共通です。切替時は既存の制約が適用されるため、部品をそのまま保つ場合は「サイズ変更時に制約を適用」をオフにしてください。これはキャンバスサイズ対応であり、PowerPoint形式の出力や用紙実寸での印刷設定は含みません。

## 線・矢印の作成

「線を描く」で直線・矢印・折れ線・曲線を選び、キャンバスをクリックします。直線と矢印は2点で確定。折れ線と曲線は点を順番に置き、「確定」またはEnterで完了、Escまたは「取消」で中止します。曲線は通過点の方向を滑らかにつなぎます。部品一覧から定形の線も追加できます。

線を選択すると、右側の「線の設定」で太さ1〜32pxのスライダー、12色パレット、任意色のカラーピッカーを使えます。区切り線にも太さと色を設定できます。線は移動・リサイズ・グループ化・Undo/Redoに対応し、HTMLへSVGとして出力します。作成後の頂点の個別移動は未対応です。

旧JSONは引き続き読み込めます。新しい線はversion:1に追加のtype、points、stroke、strokeWidthを保存するため、新しい線を含むJSONを旧アプリで読み込むことは保証しません。
