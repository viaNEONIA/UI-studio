# 会議ノート

旧名称「UI Studio」から「会議ノート」へ名称を変更しました。既存のJSON・復元データ・保存済みプロパティを引き続き使用できます。GitHubリポジトリのURLは従来の `viaNEONIA/UI-studio` を使用します。

**PC内で使う、図面への書込み・会議資料・画面ラフの編集ツール。**

PDFや画像を背景に取り込み、線・矢印・図形・文字を重ねて編集できます。Teams会議で画面を共有しながら確認事項を記入し、会議後にJSON・HTML・PNG・PDF・PowerPoint形式で保存する用途を想定しています。スマートフォンUIのラフ作成用の部品も備えています。

ビルド済みのHTMLをChromeまたはEdgeで開いて使用します。**サーバー・GitHub Pages・使用時のNode.jsは不要です。** ローカル資料の取込・描画・出力はブラウザ内で処理し、配布版には必要なライブラリを同梱しています。

> 試作版です。対応ブラウザでの操作をChromiumの自動テストで確認しています。正式なMaterial Design 3コンポーネント実装ではありません。

## 使い始める

### ビルド済みHTMLを取得する

1. [Releases](https://github.com/viaNEONIA/UI-studio/releases)から正式版、または[最新開発版](https://github.com/viaNEONIA/UI-studio/releases/tag/latest-dev)を開きます。
2. **Assets → `kaigi-note.zip`** をダウンロードします。単独の `index.html` と `THIRD_PARTY_NOTICES.txt` も添付しています。
3. ZIPを展開し、`index.html` をPC内の決まった場所へ保存します。
4. ChromeまたはEdgeで開きます。

ReleaseのファイルにはCI成果物の14日という保存期限はありません。最新開発版は更新され、正式版はバージョンごとに保存されます。従来の[ActionsのCI一覧](https://github.com/viaNEONIA/UI-studio/actions/workflows/ci.yml)からも **Artifacts → `kaigi-note-app`** を取得できます（14日保持・ログインが必要な場合があります）。リポジトリ直下の `index.html` は開発用です。**PDF取込・PNG/PDF/PPTX出力には、ビルド済みのHTMLを使用してください。**

### Releaseの自動更新

- `main`へのpushで全テスト・ビルド・配布ZIPの作成が成功すると、`latest-dev`タグの「会議ノート 最新開発版」を更新します。最新のmainを追い越した古いビルドは公開しません。
- `v0.7.0`などのバージョンタグをpushすると、同じ検証を通過した成果物で版ごとのReleaseを作成します。`v0.7.0-rc.1`などはプレリリースになります。公開済みの正式版のファイルは再実行で上書きしません。
- 添付するのは `index.html`、ライセンス同梱の `kaigi-note.zip`、`THIRD_PARTY_NOTICES.txt` です。テストに使ったビルド済みファイルをそのまま使用します。
- PRと作業ブランチのCIではReleaseを公開しません。公開専用ジョブだけにRelease書込み権限を付与し、追加の個人用トークンは不要です。

正式版を作成する場合は、検証したmainのコミットにタグを付けてpushします。

```sh
git switch main
git pull --ff-only
git tag v0.7.0
git push origin v0.7.0
```

### 起動から保存まで

1. 初回は「新規作成 — 画面設定」でキャンバスサイズを指定します。背景画像・PDFの取込は任意です。
2. 前回の保存データがある場合は、**「前回を復元」「新規作成」** を選びます。開始方法を決めるまで前回データは上書きしません。
3. 左のレイヤー一覧、上部の作図アイコン、右のプロパティで編集します。
4. 会議では「会議表示」を使い、Teams側でブラウザのウインドウを共有します。
5. 編集を続けるためのデータは、**「JSON保存」** で保存します。

## 主な機能

### PDF・画像を背景にして書き込む

- PDFは1ページを1編集ページへ変換し、キャンバス内へ縦横比を保って配置します。
- 背景資料は通常部品と別の専用レイヤーに置き、常に最背面・初期ロック状態にします。
- 背景の表示・非表示、濃さ、ページに合わせる、差し替え、削除に対応します。ロックを解除すると移動できます。
- ページの追加・複製・切替、一覧のダブルクリックによるページ名変更ができます。

### 図形・文字・線

- 四角形、円・楕円、三角形、テキスト、直線、矢印、折れ線、曲線を配置できます。
- 図形の枠線色・背景色・文字色は、パレットまたは任意色で指定できます。塗りと枠線の透明度は別々に設定できます。
- 文字を表示する部品をダブルクリックすると、文字入力・サイズスライダー・プレビューを開きます。
- 線の太さ・透明度・始点と終点の形（なし・矢印・○）を変更できます。
- 線の頂点を個別に移動し、区間への制御点追加・指定点の削除で連続した形を編集できます。
- 直線・矢印・折れ線・曲線は線の近くで選択し、斜め線の外接長方形の余白から背後の部品を操作できます。

### レイヤー・スタンプ・保存済みプロパティ

- レイヤー名は「オブジェクト名＋表示内容の先頭10文字」で識別します。
- 選択部品は編集中だけ一時的に最前面となり、上に別の部品が重なっていても操作できます。保存・出力の重なり順は変えません。
- ロック中の部品は編集選択できません。一覧の行を押すと位置へ移動し、鍵ボタンからロックを解除できます。
- 複数選択、グループ化、整列、前後への並べ替え、Undo/Redoに対応します。
- 画像をスタンプとして複数登録し、繰り返し配置できます。複数選択による配置・登録削除にも対応します。
- 色・線幅・透明度・文字サイズ・幅と高さ・制約などを種類別に保存し、次回作成時に自動適用できます。保存済みプロパティは別ファイルへ書出し・読込できます。

### 補助線・角度固定・表示移動

- 垂直・水平補助線は **アイコン → カーソルで位置決め → Enterで挿入**。プレビューを表示し、Escで取り消します。
- 数値指定と2点指定の補助線も使えます。個別削除・現在ページ内の一括削除に対応します。
- 角度固定は指定した角度の刻みに吸着します。45°なら水平・垂直・斜めを含む8方向です。
- Ctrlで部品の中心・辺・三分割点、線上の点、補助線や交点へ吸着できます。接続先の部品を動かした場合の自動追従は行いません。
- 「画面設定」で、キャンバス全体に表示する十字カーソルを切り替えられます。
- スクロール・拡大縮小・全体表示を挟んでも、作図ツールと入力済みの点を保持します。

## 保存・出力の違い

| 形式 | 対象 | 用途・編集可否 |
| --- | --- | --- |
| JSON | プロジェクト全体 | 背景・部品・スタンプ・補助線を含む再編集用データ。会議ノートへ読み込んで続きから編集 |
| HTML | 全ページ | 背景・部品を含む単独閲覧用。編集の続きにはJSONを使用 |
| PNG | 現在のページ | キャンバス全体を1枚の画像に合成 |
| PDF | 全ページ | 元PDFと通常の文字・線・図形をベクターで合成。写真・スタンプ・UI部品等は画像 |
| PPTX | 全ページ | 1編集ページを1スライドとして画像合成。PowerPoint上で文字や図形を個別編集する機能は未実装 |

PNG/PPTXは最大辺3200px・最大2倍の画像合成です。PDFの元ページ・文字・線・図形にはこの画像解像度上限を適用しません。表示倍率や画面内に見えている範囲にかかわらず、キャンバス全体を対象にします。選択枠・作図用補助線・十字カーソル・レーザーポインターは出力に含めません。

PDF/PPTXはA1〜A4の対応プリセットを実寸の用紙・スライドサイズにし、それ以外の寸法は96 CSS px/inで換算します。

## 基本操作

| 操作 | 方法 |
| --- | --- |
| 直線・矢印の作成 | ツールを選び、始点・終点をクリック |
| 折れ線・曲線の作成 | 点を順にクリックし、Enterまたは「確定」で完了 |
| 作図の取消 | Escまたは「取消」 |
| 水平・垂直固定 | 作図中・頂点移動中にShift |
| 接続位置へ吸着 | 作図中・頂点移動中にCtrl |
| 複数選択 | CtrlまたはShiftを押しながら部品・レイヤーを選択 |
| 文字編集 | 対応する部品をダブルクリック |
| 文字編集の確定 | 確定ボタンまたはCtrl＋Enter。Enter単独は改行 |
| 文字編集の取消 | Esc。日本語変換中のEnterは確定操作に使いません |
| 拡大・縮小 | キャンバス上のホイール（Ctrl不要）、下中央の＋/−、画面設定の表示倍率 |
| 表示位置の移動 | 中ボタンドラッグ、矢印キー、または手のひらONで左ドラッグ |
| 全体を中央に表示 | 下中央の「全体表示」 |
| コピー・貼付け・元に戻す | Ctrl＋C / Ctrl＋V / Ctrl＋Z（Macでは対応する操作にCommandも使用可） |
| 選択部品を削除 | Delete / Backspace、または削除ボタン |

文字入力・数値入力・セレクト操作中には、キャンバス用のキー操作が割り込まないようにしています。「閲覧モード」は編集を停止する切替、「会議表示」は左右の編集パネルを隠す切替です。

## キャンバスサイズ

A1・A2・A3・A4の縦横、スマートフォン・タブレット、HD・Full HD・QHD・2K・4Kを選べます。自由設定は幅・高さそれぞれ1〜20000 CSS pxです。

| プリセット | 横向きの寸法（CSS px） |
| --- | --- |
| A4 | 1123 × 794 |
| A3 | 1587 × 1123 |
| A2 | 2245 × 1587 |
| A1 | 3179 × 2245 |
| HD | 1280 × 720 |
| Full HD | 1920 × 1080 |
| QHD | 2560 × 1440 |
| 2K（DCI） | 2048 × 1080 |
| 4K（UHD） | 3840 × 2160 |

寸法はプロジェクト内の全ページ共通です。サイズ変更時は既存部品の制約を適用できます。位置・寸法をそのまま保つ場合は「サイズ変更時に制約を適用」をオフにしてください。

## データ保存と制限

- 自動復元はブラウザ内のIndexedDB、保存済みプロパティはlocalStorageを使います。十字カーソルの設定もブラウザに保存します。
- 復元データや設定は、同じブラウザ・同じHTMLの保存場所での使用を前提にしてください。ブラウザデータの削除、PC変更、HTMLの移動に備え、JSONとプロパティ設定の書出しファイルを保存してください。
- PDF取込は50MB・50ページまで、背景画像は25MBまで。PDFは元ファイルと表示用PNGプレビューを保持します。背景画像の取込は長辺2400pxを上限とします。
- 暗号化・パスワード付きPDFは非対応です。PNG/PDF/PPTX出力ではHTML部品（iframe）と外部URL画像をエラーとして扱います。PDFは追加CSSを含む部品も出力前にエラーとして扱います。PNG/PPTXの追加CSSには描画差が生じる場合があります。
- スタンプは最大30個、最長辺1024px以内のPNGとして保持します。補助線は1ページ1000本、保存済みプロパティは100件までです。
- 既存JSON（version:1）の読込互換性を維持します。新しい部品・背景等を含むデータを旧アプリで読み込むことは保証しません。

## ライセンス

ライセンスは未設定です。

### PDFの拡大表示

新しく取り込んだPDFは元ファイルを文書ごとに1つ保持し、各ページから参照します。表示倍率・表示範囲・画面の画素密度に合わせて、見えている部分を元PDFから再描画します。画面外まで巨大な画像にする処理を避け、再描画は1回ずつ実行し、不要になった描画を取り消します。表示用キャンバスは最大約840万画素です。

元PDFはJSON保存・自動復元にも含まれます。PDF出力は元ページと文字・線・図形をベクターで合成します。PNG/PPTX出力では元PDFから出力解像度に合わせて描画し、合成画像の上限（長辺3200px・最大2倍）は従来どおりです。閲覧用HTMLにはプレビュー画像を出力します。

旧版の保存データには元PDFが含まれないため、拡大時の改善にはPDFの再取込または背景の差し替えが必要です。スキャンなど、元PDF内の画像自体が低解像度の場合は元の画像以上には鮮明になりません。元PDFの保存によりJSONと自動保存の容量は増えます（PDF1ファイル50MB、元PDF合計はBase64換算100MB、取込後のプロジェクトは160MBを上限とします）。

### ベクターPDFの互換性と制限

- 元PDFのベクターや埋込画像を再画像化せず合成します。写真・スキャンをベクターへ変換したり高精細化する機能ではありません。
- 日本語文字は同梱の「Kaigi Note Sans JP」を埋め込みます。編集画面の文字位置・折り返し・行間を測定し、埋め込み文字を同じ表示領域へ合わせます。フォント自体の字形には差がありますが、PDF用フォントによる再改行は行いません。一般的な日本語・英数字・記号を収録し、未収録の漢字・絵文字等は欠落防止のためエラーにします。出力PDFには使用した文字だけをサブセットで埋め込み、不要な文字を含むフォント全体の埋め込みを避けます。
- 複雑なUI部品は部品単位のPNGで合成し、出力完了メッセージで個数を表示します。HTML部品・外部URL画像・追加CSSには対応せず、出力前に理由を表示します。
- 元PDFの注釈と通常のURL・ページ内リンクを保持します。フォームは入力値を表示内容として固定し、出力後の入力欄としては残しません。互換が難しいフォームは表示画像に切り替えます。参照先ページがノートにないリンクや対応外の動作は除外した件数を表示します。元PDFの電子署名や対話機能を維持する出力ではありません。
- 旧データに元PDFがない場合、背景は保存済みPNGの画質のままです。通常の文字・線・図形はベクターで出力します。

### 配置と作図の初期値

- 四角・三角・円：アイコンを押し、カーソル中心に追従するプレビューで位置を決め、Enterで設置します。クリックでは設置せず、Escで取り消します。
- 直線・矢印は2点、折れ線・曲線は点を指定してEnterで確定します。確定後も同じ作図ツールが有効なので、次の始点から続けて描けます。Escで作図を終了します。
- 2点補助線は始点と終点の間だけに表示・吸着します。水平・垂直補助線はキャンバス全体を通ります。旧データの無限補助線は従来どおり読み込めます。
- 線の標準初期値は赤（`#ff0000`）・2px。四角・三角・円は赤枠2px・背景透明です。
- **画面設定 → オブジェクトの初期値**から、選択中の部品がなくても種類別に寸法・色・太さ・背景透明などを変更できます。新規作成分に適用し、配置済みの部品は変更しません。初期値は同じブラウザに保存され、プロパティ設定のJSON書き出しにも含まれます。

### テキスト配置・補助線スナップ・文字編集

- テキストも四角・三角・円と同様に、アイコン選択 → カーソル中心でプレビュー → Enterで設置します。クリックでは設置せず、Escで取り消します。設定した寸法・文字サイズなどの初期値を使用します。
- 水平・垂直・2点補助線の配置中はCtrlで他オブジェクトへ吸着します。端点・中央・三分割点に加え、直線・折れ線上の任意位置や図形の辺も対象です。曲線・楕円の輪郭は128区間の近似で判定します。Shiftの水平・垂直制約と角度固定を維持し、線分の延長部分には吸着しません。Ctrlを離すと自由位置へ戻ります。ロックされた部品も参照対象にできます。
- 文字を持つオブジェクトをダブルクリックすると、文字・サイズ・文字色パレット・自由な文字色・横位置（左／中央／右）・縦位置（上／中央／下）を編集できます。変更はプレビューに表示し、確定時にまとめて保存します。取消は変更を破棄し、Undoは1回で戻します。HTML部品の色と配置はHTMLソース側で指定します。

### オブジェクト呼び出しキー

編集画面で使用します。文字入力中、IME変換中、ダイアログ表示中、閲覧中は作図ショートカットを無効にします。既存のCtrl+C/V/Zは維持します。キーの長押しによる連続呼び出しも抑止します。`?` または画面の「キー一覧」で一覧を開き、項目のクリックでも呼び出せます。

| キー | 呼び出し |
|---|---|
| T / R / O / Y | テキスト／四角／円・楕円／三角 |
| L / A / P / C | 直線／矢印／折れ線／曲線 |
| G / H / V | 2点補助線／水平補助線／垂直補助線 |
| S | 選択ツール |
| Shift+B / Shift+I / Shift+M / Shift+H | ボタン／入力欄／画像／HTML |
| Shift+N / Shift+C / Shift+A / Shift+F | 下部ナビ／チェック／アプリバー／検索バー |
| Shift+D / Shift+S / Shift+T / Shift+P | カード／スイッチ／タブ／チップ |
| Shift+G / Shift+V / Shift+L / Shift+J | FAB／進捗バー／区切り線／リスト項目 |
| Shift+E / Shift+K / Shift+X / Shift+R / Shift+O | バッジ／スライダー／複数行入力／ラジオ／ボトムシート |

テキスト・図形はEnter配置、線は点を指定して作図します。Material部品は従来と同じ中央追加です。

### PDFのテキスト配置

PDF出力では編集画面と同じフォント設定で文字位置・自動折り返し・手動改行を測定します。測定後に専用フォントを同じ文字領域へベクターで埋め込み、出力専用フォントの文字幅や行高による余分な改行・欠けを防ぎます。中央・右揃え、縦位置、表示倍率に対応し、出力時に元データの幅・高さ・文字サイズは変更しません。編集画面ですでに枠外へはみ出している文字は、画面と同じ範囲で切り取られます。

### 2点の中央から配置

「図形・線・文字」の **2点の中央から配置** をON（ショートカット `M`）にしてから、配置する部品・作図ツールを選びます。基準の2点をクリックすると黄色の中点マークを表示します。

- テキスト・四角・円・三角・Material部品：中点を部品の中心としてプレビューし、Enterで設置します。
- 直線・矢印・折れ線・曲線：中点を始点に設定し、続く点をクリックして描きます。作図完了後は次の基準2点を指定できます。
- 基準点はCtrlで既存の部品・線・補助線へ吸着し、Shiftの水平・垂直制約にも対応します。同じ位置を2回指定しても確定しません。
- Escで未確定の配置を破棄します。基準点と中点マークは資料には追加されず、保存・出力対象にも入りません。

2点補助線の中点には **Ctrl** でスナップできます。新規部品は中心、移動中はつかんだ部品の中心、リサイズ中は右下角、作図・頂点編集では指定点が中点へ吸着します。斜め・縦・横の線分に対応し、無限補助線には中点を設けません。吸着時に「補助線の中点」と表示します。

### PDF容量の軽量化

使用した文字だけを文書共通のフォントとしてサブセット埋め込みし、同じ背景・スタンプ画像はPDF内で共有します。ベクター、文字検索、元PDFの画質を維持します。短い日本語注記の比較例では4,315,975バイトから5,760バイトへ削減しました。元資料そのものや異なる大きな画像の容量は残るため、すべてのPDFが同じ比率で縮小するわけではありません。


## 仮配置・ノート管理

- オブジェクトはツール選択 → 左クリックで位置を仮指定 → Enterで確定します。直線・矢印・2点補助線は2点を指定してからEnter、折れ線・曲線は必要な点を指定してからEnterです。
- Backspaceは直前の仮指定を一段戻します。作図していないときはUndoです。Deleteは選択した部品の削除、Escは選択ツールへの復帰です。文字入力中のBackspaceは通常の文字削除です。
- 使用中のツール／機能は緑色で表示します。上部にスマート吸着と中央配置、出力ボタンと基本キーガイド、左側に新規ノート／ノートを開く、下部にページ移動を配置しています。
- 新しいテキストは文字の大きさと改行に合わせて背景枠を自動調整します。文字の詳細設定で自動調整を切り替えられます。手動でリサイズしたテキストは自動調整を解除します。
- 楕円は幅・高さを自由に変形でき、Ctrlを押しながら右下ハンドルをドラッグすると真円になります。四角形の4つの角ハンドルは各角だけを動かします。内側の右下ハンドルは全体サイズ変更です。サイズは0.01px以上で変更できます。
- 複数選択した部品の色・線幅・透明度・文字の大きさ／配置など、共通して持つプロパティを一括変更できます。ロック済みやその項目を持たない部品は変更しません。
- 「保存」またはCtrl+Sで編集用JSONを手動保存します。対応ブラウザでは最初に保存先を指定し、以後は同じファイルへ保存します。非対応環境ではJSONをダウンロードします。JSON保存ボタンも使用できます。
- 「ZIP保存」は、全ページ・背景の元PDF／画像・配置物・スタンプを含む `note.json` と、保存したプロパティ設定を `property-settings.json` にまとめます。ZIPを「ノートを開く」から読み込むとノートと設定を復元できます。
- 新規ノート作成は現在のノートを置き換えます。作成画面から現在のノートをZIP保存するか、キャンセルして作業へ戻れます。
- 資料取込時は、そのページの寸法にキャンバスを合わせます。PDFは元PDFのページ寸法、PNG／HTMLは配置した背景全体の寸法で出力します。混在するPDFページサイズも保持します。PPTXは全スライド共通のサイズとなる形式のため、先頭ページのサイズを使い、他のページは縦横比を保って収めます。


## 図形の指定とマウス操作

| 状態 | 左ボタン | Ctrl | Shift | 確定 |
|---|---|---|---|---|
| 四角の新規作成 | 対角の1点目 → 2点目で仮確定 | 既存オブジェクト等へ吸着 | ― | Enter |
| 丸の新規作成 | 中心 → 半径を動かしてクリックで仮確定 | 既存オブジェクト等へ吸着 | ― | Enter |
| 仮確定した図形・文字・部品・線 | プレビューをドラッグして全体移動 | 移動位置の吸着 | 水平・垂直に移動 | Enter |
| 四角の角ハンドル | 通常は1つの角だけ自由に変形 | 変形開始時に正方形なら正方形、その他は長方形を維持 | 角を水平・垂直の一方向へ移動 | ボタンを離す |
| 三角の角ハンドル | 通常は1つの角だけ自由に変形 | 変形開始時の三角形の比率を維持 | 角を水平・垂直の一方向へ移動 | ボタンを離す |
| ペン／蛍光マーカー | 押している間に描画 | 最初の進行方向に合わせて水平・垂直固定 | ― | ボタンを離すと1ストローク確定 |
| 表示移動 | 手のひらモードでドラッグ | ― | ― | ― |

- CtrlとShiftを同時に使う角変形は、Ctrlの形状維持を優先します。四角と三角の比率判定はドラッグを開始した時点で行います。
- 丸の半径指定は、中心を押したままドラッグする方法と、中心をクリックしてからマウスを動かす方法の両方に対応します。半径の位置でクリックして仮確定します。
- 中央配置を使う四角・丸は、基準2点で中心を求め、その後に大きさを指定して仮確定します。仮確定後もプレビューを移動できます。
- 仮確定中の移動はプレビュー上、配置済みの移動は選択ツール、描画はペン専用モードで受け取ります。中ボタンは表示移動、右ボタンはオブジェクト作成に使いません。
- ペンと蛍光マーカーは上部の専用アイコンから呼び出します。種類・色・太さは右ペインで設定し、蛍光マーカーは半透明で描きます。ストロークごとにUndoできます。
- 図形の変形ハンドルは、倍率によらず画面上で10.5px（従来の1.5倍）です。四角・三角は選択した直後から角ハンドルを表示します。
