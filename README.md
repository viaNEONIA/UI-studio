# 会議ノート

PDFの図面に線・図形・文字を書き込み、会議中の確認事項や決定事項を残す、PCブラウザ向けの編集ツールです。Teamsなどで画面を共有しながら使えます。画像を背景にした資料作成や、UIの画面ラフ作成にも対応しています。

旧名称は「UI Studio」です。リポジトリ名は `viaNEONIA/UI-studio` のままです。旧版のJSON、復元データ、保存済みプロパティは引き続き読み込めます。

**ビルド済みの `index.html` をChromeまたはEdgeで開いて使用します。利用時にサーバーやNode.jsは不要です。** PDFの取り込み、編集、出力はブラウザ内で処理し、必要なライブラリと日本語フォントは配布ファイルに同梱しています。現在は試作版です。

## 使い始める

1. [最新開発版](https://github.com/viaNEONIA/UI-studio/releases/tag/latest-dev)の **Assets → `kaigi-note.zip`** をダウンロードします。
2. ZIPを展開し、`index.html` をPC内に保存します。ライセンス表記の `THIRD_PARTY_NOTICES.txt` も同梱しています。
3. ChromeまたはEdgeで `index.html` を開きます。
4. 「新規作成」でキャンバスを用意するか、保存したノートを開きます。前回の復元データがある場合は「前回を復元」も選べます。
5. 必要に応じてPDF・画像を取り込み、線・図形・文字を書き込みます。
6. 編集を再開するために **JSONまたはZIPを保存**し、配布・閲覧用にはPDFやHTMLを出力します。

単独の `index.html` もReleaseに添付しています。リポジトリ直下の `index.html` は開発用です。**PDF取り込みやPNG・PDF・PPTX出力には、ビルド済みHTMLを使用してください。**

Releaseの配布物には、Actions成果物のような14日間の保存期限はありません。`latest-dev` は更新されるため、使用版を残す場合は手元に保存してください。[Actions](https://github.com/viaNEONIA/UI-studio/actions/workflows/ci.yml)の `kaigi-note-app` からも取得できますが、こちらは14日間の保持で、ログインが必要な場合があります。

## 作図と編集

### 図形・文字の配置

| 対象 | 配置方法 |
| --- | --- |
| 四角形 | 対角の2点をクリック。2点目で確定 |
| 円 | 中心をクリックし、半径を指定してクリックすると確定。配置後は楕円にも変形可能 |
| 直線・矢印・2点補助線 | 始点と終点をクリック。2点目で確定 |
| 折れ線・曲線 | 点を順にクリックし、Enterまたは「確定」で完了 |
| 文字・三角形・UI部品 | ツール選択後、クリックで仮配置し、Enterで確定 |
| 水平・垂直補助線 | アイコン選択後、クリックで位置を仮指定し、Enterで確定 |
| 引き出し線付きテキスト | 指示先、テキストの配置位置の順に2点をクリックして確定 |
| ペン・蛍光マーカー | 左ボタンを押している間に描画。ボタンを離すと確定 |

確定後も同じ作図ツールで続けて配置できます。Backspaceは未確定の指定を1段階戻し、作図中でなければUndoを実行します。Escで作図を取り消し、選択ツールへ戻ります。

- 文字のある部品はダブルクリックで、文字・サイズ・色・横位置・縦位置を編集できます。Ctrl+Enterまたは確定ボタンで反映し、Escで取り消します。Enter単独は改行です。
- 新しいテキストの枠は文字と改行に合わせて自動調整します。詳細設定で切り替えられ、手動リサイズ後は自動調整を解除します。
- 図形の塗りと枠線は、色・透明度を別々に指定できます。線は太さ・透明度・始点と終点の記号（なし・矢印・○）を変更できます。
- 直線・折れ線・曲線は頂点や制御点を編集できます。四角形・三角形は角ごとの自由変形に対応しています。
- 引き出し線付きテキストは先端と折れ点を移動できます。枠・引き出し線・文字を1つのオブジェクトとして保持します。
- 線の標準初期値は赤（`#ff0000`）・2px、四角形・三角形・円は赤枠2px・背景透明です。「画面設定 → オブジェクトの初期値」で種類別に変更できます。配置済みの部品には影響しません。

### 引き出し線の文字枠と円の中心

- 引き出し線付きテキストを選ぶと、指示先・折れ点のハンドルに加え、**文字枠の四隅に青い四角ハンドル**を表示します。角をドラッグすると、反対の角を固定して文字枠の幅・高さを変更します。台形等への自由変形ではありません。
- 指示先の座標と文字サイズは保持し、文字は枠幅に合わせて折り返します。折れ点と接続点は枠の近い側へ追従します。文字枠は幅24px・高さ16px以上です。右パネルの「引き出し線の文字枠」でもX・Y・幅・高さを変更できます。通常の位置・サイズ欄は引き出し線全体の寸法です。
- 「画面設定 → 円・楕円の中心」で **選択時・移動中／常時表示／非表示**を切り替えます。表示設定はブラウザに保存します。右パネルには選択中の円の中心X・Yも表示します。
- 円・楕円を移動すると、スマート吸着ON時は中心を優先して他の部品の中心・補助線・交点へ合わせます。吸着範囲は画面上8pxを基準に倍率に合わせて調整します。中心マークを非表示にしても、吸着は独立して有効です。
- 中心マーク、選択ハンドル、吸着ガイドは編集用表示です。閲覧モード・会議表示では中心マークを隠し、PDF・HTML・PNG・PPTXや範囲指定スタンプには含めません。図形・文字枠の保存は従来のJSON構造を維持します。

### 吸着・角度固定・中央配置

- **F**でスマート吸着、**Q**で角度固定のON/OFFを切り替えます。角度固定は指定した角度の刻みに合わせます。45°なら水平・垂直・斜めを含む8方向です。
- **Ctrl**で部品の端・中心・三分割点、線上の点、補助線・交点・2点補助線の中点へ吸着できます。ロック中の部品も参照できます。接続先を動かした際の自動追従は未実装です。
- 作図・頂点移動中の **Shift** は水平・垂直を固定します。四角形の角変形では正方形・長方形の形状、三角形では元の比率、楕円のサイズ変更では真円を維持します。角変形の制約はドラッグ開始時のキーで決まります。
- ペン・マーカーもShiftで水平・垂直を固定します。Ctrlは軸固定用ではありません。
- **M**で「2点の中央から配置」を切り替えます。基準2点から求めた中点に文字・三角形・UI部品を設置できます。四角形・円はさらにサイズを指定し、線は中点を始点に描きます。基準点と中点マークは出力しません。
- 2点補助線は指定した区間だけ、水平・垂直補助線はキャンバス全体に表示します。補助線は個別または現在ページ内で一括削除できます。

### レイヤー・結合・スタンプ

- CtrlまたはShiftを押しながら部品・レイヤーをクリックすると複数選択できます。共通の色・太さ・透明度・文字設定を一括変更できます。
- レイヤーの前後移動、ロック、グループ化、整列、複製、Undo/Redoに対応しています。ロック中の部品は編集できず、一覧から位置の確認とロック解除ができます。
- **グループ化**は複数レイヤーを保ったまま一緒に移動する機能です。**結合**は構成要素を保持してレイヤーを1件にまとめる機能です。「分解」で現在の位置・寸法を反映した個別要素に戻せます。結合物の色・文字は分解して編集します。
- 結合後のサイズ変更は構成要素の位置と寸法に適用し、文字サイズと線幅は維持します。PDF出力時は構成要素に展開するため、PDF上で1つの結合物としては保持しません。
- 画像をスタンプとして登録し、繰り返し配置できます。複数画像の登録・配置・登録削除にも対応します。
- 「スタンプ → 画面からスタンプ作成」でキャンバス内を矩形に切り出せます。登録前プレビューで背景を含める／透過を選択し、不透明度（0〜100%）を確認して登録します。「範囲を選び直す」とキャンセルにも対応し、登録確定まではノートを変更しません。
- 背景透過ではPDF・背景画像を除外して前景をPNGにします。背景と前景が一体化した画像の自動背景除去は行いません。選択枠・補助線・ハンドル・カーソルなどの編集UIは含めません。
- 登録後のスタンプ一覧と、配置した画像のプロパティで不透明度を変更できます。JSON・ZIPで保存・復元し、HTML・PNG・PDF・PPTXにも反映します。
- 種類別の寸法・色・線幅・文字などをプロパティ設定として保存し、別ファイルへ書き出し・読み込みできます。

## 背景資料とページサイズ

PDFは1ページずつ編集ページに取り込みます。背景は専用の最背面レイヤーに配置し、初期状態ではロックします。表示・非表示、濃さ、ページへのフィット、差し替え、削除に対応し、ロック解除後は移動できます。ページの追加・複製・切替と、一覧のダブルクリックによるページ名変更も可能です。

取り込んだPDF・画像に合わせて、そのページのキャンバス寸法を設定します。異なるサイズのPDFページも保持できます。プリセットはA1〜A4の縦横、スマートフォン・タブレット、HD・Full HD・QHD・2K・4Kです。自由設定は幅・高さ各1〜20000 CSS pxです。サイズ変更時は既存部品の制約を適用するか選べます。

新しく取り込んだPDFは元ファイルを保持し、表示倍率・表示範囲・画面の画素密度に合わせて再描画します。描画済み画像とページ情報のキャッシュで画面移動時の再描画を抑えます。元から低解像度のスキャン画像を高精細化する機能ではありません。元PDFを含まない旧データは、背景の再取り込みが必要です。

## 保存・出力

上部の「保存ファイル名」を各形式で共通して使用し、拡張子や用途別の接尾辞を自動で付けます。使用できない文字は `_` に置き換えます。保存名はJSON・ZIP・復元データに保持します。

「保存」またはCtrl+Sは編集用JSONを保存します。保存先の選択に対応するブラウザでは、初回に選んだファイルを次回以降も使用します。「名前を付けて保存」はJSONの保存先を選び直します。それ以外の形式は各出力ボタンを使用してください。保存先選択に非対応の環境では、指定したファイル名でダウンロードします。

| 形式 | 対象 | 内容・編集可否 |
| --- | --- | --- |
| JSON | ノート全体 | 全ページ・背景・部品・スタンプ・補助線を保存。会議ノートで再編集するためのデータ |
| ZIP | ノート全体と設定 | 元PDF・背景・部品等を含む `note.json` と `property-settings.json` を保存。「ノートを開く」から復元可能 |
| HTML | 全ページ | 単独の閲覧用ファイル。編集再開にはJSON・ZIPを使用 |
| PNG | 現在のページ | ページ全体を1枚の画像に合成 |
| 通常PDF | 全ページ | 元PDFと追加した文字・線・図形をベクター合成。追加要素はページ本文になる |
| 注釈編集用PDF | 全ページ | 追加した文字・線・図形・手書きをPDF注釈として保存。対応ソフトで編集可能 |
| PPTX | 全ページ | 1ページを1スライドの画像として保存。文字・図形の個別編集は未実装 |

選択枠・作図用補助線・十字カーソル・レーザーポインターは出力しません。画面の表示範囲によらずページ全体を出力します。PNG・PPTXの画像は最大辺3200px・最大2倍です。この上限はPDFのベクター要素には適用しません。PDFの写真・スタンプ・複雑なUI部品は画像として合成します。

PDFは元資料のページ寸法を保持します。用紙プリセットは実寸で出力し、その他の寸法は96 CSS px/inで換算します。PPTXは全スライド共通サイズのため、先頭ページの寸法を使い、他のページは縦横比を保って収めます。

### PDF注釈・コメント・作成者

上部の「出力」メニューで「PDF方式」を選び、「PDF出力」を押します。初期値は通常出力です。

| 会議ノートの要素 | 注釈編集用PDFでの種類 |
| --- | --- |
| 文字 | FreeText |
| 引き出し線付きテキスト | 引き出し線情報を持つFreeText（FreeTextCallout） |
| 直線・矢印 | Line |
| 四角形・円／楕円 | Square・Circle。変形した四角形はPolygon |
| 三角形・折れ線 | Polygon・PolyLine |
| 曲線・ペン・蛍光マーカー | Ink。色・透明度を保持 |

図形内の文字は図形と別のFreeText注釈になります。画像・スタンプ・UI部品は通常合成し、追加注釈はその上に表示します。会議ノートのレイヤー構造や結合単位をPDF編集ソフトへ引き継ぐ機能は未実装です。

- 右パネルの「PDF注釈コメント」に本文を入力できます。文字へのコメントは表示文字と分けて返信注釈として保存します。通常出力ではコメント本文をページに表示しません。
- 「画面設定 → PDF出力オプション」で追加注釈・コメントとPDF文書の作成者を変更できます。空欄にもできます。元PDFの既存注釈の作成者・日時は保持します。
- 追加オブジェクトの作成日時・更新日時を保存し、注釈の日時に使用します。選択や出力のみでは更新しません。日時のない旧データは出力日時を使います。
- 元PDFの注釈と対応するURL・ページ内リンクを保持します。フォームは入力値を表示として固定し、入力欄としては残しません。互換性の難しいフォームは画像化し、参照先のないリンク等は除外件数を表示します。電子署名やすべての対話機能の維持は対象外です。
- 画面とPDFで同梱日本語フォントを共用し、文字送り幅・改行位置を維持します。使用した字形だけを埋め込み、同一画像も共有して容量を抑えます。未収録文字は見た目の1文字単位で「〓」へ置換し、警告と文字置換一覧TXTを出力します。通常／注釈編集用PDFの両方に適用し、元のノート・JSON・ZIPの文字は変更しません。フォント自体の読込・生成エラーは別途通知します。
- 外部ソフトで再編集すると、フォントや再描画方法により改行・文字配置・角丸等が変わる場合があります。文字の回転と埋め込みフォントの不具合は修正実装済みですが、**Acrobat実機での最終確認は未実施**です。修正前のPDFには反映されないため、修正版HTMLから再出力してください。


## 不具合・要望の管理

不具合の報告と修正確認は[GitHub Issues](https://github.com/viaNEONIA/UI-studio/issues)で管理します。READMEには利用者に影響する既知の制限を要約し、再現条件・修正履歴・検証結果はIssueに記録します。

| 区分 | 管理先 | 状態 |
| --- | --- | --- |
| AcrobatでのPDF注釈再編集（引き出し線の色、テキストの配置など） | [Issue #41](https://github.com/viaNEONIA/UI-studio/issues/41) | 実機検証・修正確認待ち |
| 未実装の将来機能 | [Issue #24](https://github.com/viaNEONIA/UI-studio/issues/24) | 未実装 |

修正を完了扱いにする際は、対象コミット、検証環境、再現手順、修正後の結果をIssueへ記録してください。自動テスト成功のみではAcrobat実機の互換性確認を完了としません。

### 実装済み対策の実機確認

実装済み項目は未修正の不具合一覧から除外し、確認が残るものだけを[検証記録](docs/VALIDATION.md)で管理します。引き出し線の色指定、文字回転、埋め込み日本語フォントは対策実装済みですが、Acrobat実機での再編集・保存・再表示は未確認です。自動検証の成功をAcrobat実機確認の完了とは扱いません。

## データ保存と制限

- 自動復元はIndexedDB、プロパティ設定などはlocalStorageを使用します。同じブラウザ・同じHTMLの保存場所での使用を前提にしてください。PC変更・HTMLの移動・ブラウザデータ削除に備え、JSONまたはZIPも保存してください。
- 新規ノート作成は現在のノートを置き換えます。作成前にZIP保存するか、キャンセルして作業へ戻れます。
- PDF取り込みは1ファイル50MB・50ページまで、元PDF合計はBase64換算100MBまで、取り込み後のプロジェクトは160MBまでです。元PDFを保持するため保存データの容量は増えます。
- 背景画像は25MBまで、長辺2400pxを上限に取り込みます。スタンプは最大30個・最長辺1024px以内のPNGで保持します。補助線は1ページ1000本、保存済みプロパティは100件までです。
- 暗号化・パスワード付きPDFは非対応です。HTML部品（iframe）と外部URL画像はPNG・PDF・PPTX出力に対応しません。追加CSSのある部品はPDF出力に非対応で、PNG・PPTXでも表示差が生じる場合があります。
- 旧JSON（`version:1`）の読み込み互換性を維持します。新機能を含むデータを古いアプリで開くことは保証しません。

## HTMLスライドへの修正指示

動作確認用に[2ページのHTMLサンプル](docs/examples/html-slides-demo.html)を用意しています。表示幅640px・高さ360pxで取り込めます。

1. 「画面設定 → HTMLスライド・AI指示 → HTMLスライドを取り込む」でローカルHTMLを選びます。
2. 元のHTMLを想定した表示幅・高さと、必要ならスライドのCSSセレクターを指定します。自動検出できない文書は1ページになります。
3. 取り込んだ背景の上に既存の図形・文字・矢印・引き出し線で注釈を追加します。HTML本体の要素は直接変更しません。
4. 注釈を選択して右パネルの「AI修正指示」に修正内容と操作を入力します。「対象のHTML要素」で要素を選ぶと青い破線で対象を表示します。
5. 左パネルで元HTML資料を選び、右上の「出力 → AI指示JSON出力」を押します。「元HTML保存」と、通常の注釈付きPDF・HTML出力を合わせてAIへ渡してください。
6. 編集の再開には通常のJSONまたはZIPを保存します。原本・ハッシュ・ページとの対応・注釈・対象指定も保持します。AI指示JSONは編集用ノートとしては読み込めません。

**表示範囲：** UTF-8の単一HTML、10MB・50スライドまで。各ページ1〜4096px、1600万画素までです。インラインCSSとデータURIのPNG・JPEG・GIF・WebP画像を静的に描画します。JavaScript、外部CSS・外部画像、CSSのURL参照、Webフォント、動画、iframe等は除外します。元HTMLは保存したまま、表示用の複製だけを処理します。動的スライドや複雑なCSSは元と同じ見た目を保証できません。取り込み後は背景画像なので拡大時に画質の限界があります。

**AI指示：** スライド基準のCSS pxへ座標を変換し、ID・セレクター・対象の文字・図形座標を出力します。指示文は「AI修正指示 → PDFコメント → テキスト注釈本文」の順で取得し、指示文のない図形は除外します。対象未指定・別資料への対象指定は `review`（要確認）へ変更します（`add` は座標指定で維持）。出力前に原本のSHA-256とJSON Schemaを検証します。対象セレクターは確認用の手掛かりであり、AIによる誤適用を防ぐため原本と合わせて確認してください。

[JSON仕様](docs/AI_INSTRUCTIONS_JSON.md)にフィールドと制約を記載しています。

## 開発・ビルド・検証

Node.js **24系**を使用します。

```bash
npm ci
npm run build
```

生成した `dist/index.html` を開いて使用します。Windows PowerShellで `npm.ps1` の実行制限が出る場合は、`npm.cmd ci` / `npm.cmd run build` を使用してください。

```bash
npm test
npx playwright install --with-deps chromium
npm run test:e2e
BASELINE=1 npm run test:e2e -- --grep "group at edge|invalid import|export escapes"
```

変更は作業ブランチとPull Requestで管理します。CIは単体テスト、Chromium操作テスト、旧版回帰テスト、単独HTMLと配布ZIPの生成を行います。GitHub Pagesへの自動公開は行いません。

- `main`へのpushで検証・配布物生成が成功すると、`latest-dev`のReleaseを更新します。古いmainビルドによる配布物の巻き戻しは防止します。
- `v0.7.0`のようなバージョンタグでは版別のReleaseを作成します。`v0.7.0-rc.1`のようなタグはプレリリースです。公開済みの正式版は再実行で上書きしません。
- PR・作業ブランチのCIではReleaseを公開しません。検証したビルド済みファイルを配布に使用します。
