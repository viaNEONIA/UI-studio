# UI Studio

PCブラウザでスマートフォンUIのラフを設計する、HTML/CSS/JavaScript製のプロトタイプエディターです。

> **現在の基準版: v0.6（試作）**。実ブラウザでの操作テストは未完了です。正式なMaterial Design 3コンポーネント実装ではありません。

## 起動

`npm ci && npm run build` で配布版を生成し、`dist/index.html` をChromeまたはEdgeで開きます。配布版の使用にはサーバーは不要です。

GitHub Pagesを有効にした場合は、リポジトリの公開URLでも利用できます。外部HTMLなどの埋め込み内容は信頼できるものに限定してください。

## 既存機能（実装を含むが動作保証前）

- 画面・コンポーネント・レイヤー編集
- ドラッグ移動、サイズ変更、複数選択、グループ化
- グリッド表示、スマートガイド、スナップ
- 端末サイズ切替、倍率、レイアウト検査
- 制約ベースの位置・サイズ調整（v0.6）
- JSON保存・読込、HTML出力

## 開発上の原則

1. `index.html` はv0.6の原本として初回コミットし、以後の変更はPull Requestでレビューします。
2. 画面データはJSONを正本とし、HTML出力は生成物とみなします。
3. 新機能の前にブラウザE2Eテストを整備します。
4. JSONの後方互換性を壊す場合はマイグレーションを用意します。
5. ユーザーの設計データを無断で外部送信しません。

## GitHub Pages

Settings → Pages → Build and deployment → Source: **GitHub Actions** を選択してください。`main` へのpushで `.github/workflows/pages.yml` が実行されます。公開URLは通常 `https://viaNEONIA.github.io/UI-studio/` です（公開設定に依存）。

## A4・A3の資料作成

左側の「キャンバスプリセット」からA4・A3の縦／横を選択できます。切替時はキャンバス全体が見える倍率に自動調整します。1画面を1ページとして利用し、「＋画面」でページを追加します。

| 用紙 | 実寸 | キャンバス（CSS px） |
| --- | --- | --- |
| A4 縦 | 210 × 297 mm | 794 × 1123 |
| A4 横 | 297 × 210 mm | 1123 × 794 |
| A3 縦 | 297 × 420 mm | 1123 × 1587 |
| A3 横 | 420 × 297 mm | 1587 × 1123 |

96 CSS px/inの換算値を整数へ丸めています。JSONのversion:1とwidth/heightを引き続き使い、旧形式を変更しません。サイズはプロジェクト内の全画面共通です。切替時は既存の制約が適用されるため、部品をそのまま保つ場合は「サイズ変更時に制約を適用」をオフにしてください。PDF/PPTX出力にも用紙の実寸サイズを使用します。

## 線・矢印の作成

「線を描く」で直線・矢印・折れ線・曲線を選び、キャンバスをクリックします。直線と矢印は2点で確定。折れ線と曲線は点を順番に置き、「確定」またはEnterで完了、Escまたは「取消」で中止します。曲線は通過点の方向を滑らかにつなぎます。部品一覧から定形の線も追加できます。

線を選択すると、右側の「線の設定」で太さ1〜32pxのスライダー、12色パレット、任意色のカラーピッカーを使えます。区切り線にも太さと色を設定できます。線は移動・リサイズ・グループ化・Undo/Redoに対応し、HTMLへSVGとして出力します。線を選択すると各頂点に丸いハンドルが表示され、個別にドラッグして形を変更できます。元の部品枠の外にも移動でき、他の頂点の位置は保たれます。曲線のハンドルは曲がり方を決める制御点です。1回のドラッグは1回のUndoで戻せます。

旧JSONは引き続き読み込めます。新しい線はversion:1に追加のtype、points、stroke、strokeWidthを保存するため、新しい線を含むJSONを旧アプリで読み込むことは保証しません。

## 会議用資料・出力（ローカル処理）

開発は `npm ci && npm run build`。配布・起動には **`dist/index.html`** を使います。依存ライブラリ・PDFのCMap/標準フォントを同梱した単独HTMLのため、実行時のCDN接続は不要です。GitHub Pagesもビルド済みdistを公開します。リポジトリ直下のindex.htmlでも基本編集・レーザー・手のひら・拡大縮小・閲覧切替・画像取込・スタンプを使用できます。PDF取込とPDF/PPTX出力にはライブラリ同梱のdist/index.htmlまたは公開版が必要です。未ビルド版ではPDF/PPTX出力ボタンを無効化し、PDF取込を試した場合は理由を表示します。

1. A4/A3などのキャンバスサイズを選択して「PDF・画像を取り込む」。PDFは1ページを1編集ページに変換し、現在のキャンバス内へ縦横比を保って配置します。サイズは全ページ共通です。既存ページがあれば新しいページとして追加します。
2. 背景は常に最背面、初期状態でロック。表示/非表示・濃さ・差し替え・削除・ページに合わせるを操作できます。ロック解除すると背景をドラッグ移動できます。
3. 上に線・図形・テキストを追加します。「会議表示」で編集パネルを隠し、Teams側でブラウザのウインドウ共有を行います。ページ切替と手のひら移動も利用できます。
4. JSONは背景画像も含む再編集用正本。HTMLは背景を含めた単独閲覧用です。PDF/PPTXは全ページを画像合成して出力します。PPTXの図形・文字は個別に編集できません。A4/A3は実寸の用紙・スライドサイズを設定し、その他は96px/inで換算します。

背景を含むUndo履歴は文字数合計32Mi以内を目安に古い履歴を削除します（直前1件は保持）。

自動復旧データは端末内のIndexedDBへ保存します。前回分があると復旧/破棄の選択を表示し、選択前には上書きしません。保存失敗は画面に表示します。ブラウザのデータ削除・端末変更には引き継げないため、会議後はJSONを保存してください。JSONダウンロードのボタン操作は、保存先への書込み完了までを保証するものではありません。

取込はPDF 50MB/50ページ、画像25MBまで。背景は最長辺2400px以内に画像化します。元PDFファイル自体は保存せず、再表示用のページ画像を保存します。検索可能なPDFのテキストやベクターを維持する出力ではありません。暗号化/パスワード付きPDFは非対応です。

PDF/PPTX出力ではHTML部品（iframe）と外部URL画像を明示的なエラーにし、不完全な資料を黙って出力しません。外部URL画像は画像ファイルを背景として取り込んで使用してください。複雑な追加CSSには描画差が生じる場合があります。新規の背景フィールドを含むJSONを旧バージョンへ戻す互換性は保証しません。

### 背景の透明化
部品を選び、右側の「背景を透明にする」で背景だけを消せます。チェックを外すと元の色と透明度に戻ります。「背景の透明度」は0％（不透明）〜100％（完全に透明）で連続調整でき、文字色には影響しません。四角・文字を含む部品に適用でき、JSON保存・読込、HTML・PDF・PPTX出力にも反映されます。追加CSSで背景を指定している場合は、その指定が優先されます。

### 図形・会議操作
- Material 3の見出しをクリックすると部品一覧を折りたためます。図形・線・スタンプは別に表示します。
- 四角形・円／楕円・三角形を配置でき、塗りつぶしと枠線の色・透明度を独立して指定できます。枠線の太さ0は枠線なしです。
- レイヤー一覧のチェック、または選択部品の「レイヤーをロック」で移動・リサイズ・プロパティ編集・削除・整列を防止します。ロック解除はレイヤー一覧から行えます。
- PNG・JPEG・WebP画像をスタンプとして取り込み、一覧から繰り返し配置できます。画像は長辺1024px以内のPNGへ変換し、スタンプ一覧と配置画像をJSONに含めます（最大30個）。PNGの透過背景を維持します。
- テキストと図形内の文字は横（左・中央・右）と縦（上・中央・下）の位置を選べます。
- キャンバス上でCtrl＋ホイールを操作すると、マウス位置を基準に5〜400％で拡大・縮小します。編集・閲覧・会議表示で共通です。
- 中ボタンを押しながらドラッグ、または矢印キーで表示領域を移動します。「手のひら移動」をONにすると左ボタンでもドラッグできます。矢印キーは文字入力やセレクト操作中には割り込みません。全体表示時でも余白を含めて移動できます。
- 線の2点目以降を置く際にShiftを押すと、直前の点から水平・垂直の近い方向に固定します。
- 「閲覧モード」では編集を止め、ページ移動・拡大縮小・手のひら移動・保存／出力・レーザーを使えます。「編集モードへ」で編集を再開します。「会議表示」は編集パネルを隠す表示切替です。
- 「レーザー：OFF」をクリックするとON表示に変わり、キャンバスの中央に赤い点を表示します。資料の上へマウスを動かすと追従します。編集画面・会議画面の両方で使用でき、Escで解除します。レーザーはJSON・HTML・PDF・PPTXには含めません。Teamsではこのブラウザのウインドウを共有してください。
